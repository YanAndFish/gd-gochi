# 图像生产与验收

## 参考图检查

逐张记录：

- 主体轮廓、长宽高比例与视觉重心。
- 孔洞、拱口、接缝、支脚、把手等结构。
- 表面光泽、纹理、透明度和颜色。
- 可确认的使用方式。
- 必须移除的贴纸、条码、零售标签、水印和背景杂物。

如果样图之间出现结构矛盾，停止生成并只询问一个能够解决冲突的问题。

## 资产规格

- 商品影棚图：1120×1400 PNG。
- 编辑场景图：1120×1400 PNG。
- 新系列横幅：2048×1152 PNG。
- 每个变体至少提供：3/4 主图、正面、侧面、结构细节。
- 每个商品至少提供一张不含人物的编辑场景图。
- 适合人体互动的商品额外提供一张 1120×1400 PNG 米兰模特场景图。

坐用、穿戴、手持或携带等人物能够证明真实使用关系的商品属于适合人体互动。模特必须是不可识别为真人的虚构成年人；通过当代服装造型与克制的白色展馆或室内表达米兰语境，不依赖地标、Logo 或图片文字。人物与商品的接触、比例和姿态必须合理，并保持商品关键结构清晰可见。

原始样图归档到 `design-references/products/<product-slug>/`。生成资产统一写入 `public/assets/catalog/<product-id>/<variant-id>/`；商品共用场景和新系列横幅放在默认变体目录。写目录前读取文件真实像素，不要按生成提示猜测尺寸。

## 生成顺序

1. 从原始样图建立洁净母版。
2. 检查母版与样图的结构一致性。
3. 以母版为主要条件生成多角度图。
4. 使用已通过的商品主图生成不含人物的编辑场景图。
5. 适合人体互动时，再以已通过的主图和结构细节生成米兰模特场景；优先选择不遮挡关键结构的互动姿态。
6. 新系列最后生成横幅，避免横幅反向改变商品结构。
7. 将生成场景的 `role` 设为 `editorial-ai`、`aiConcept` 设为 `true`；米兰模特图的 caption 固定为“品牌 AI 概念影像 · 米兰造型”，alt 明确虚构成年米兰模特及互动方式。

## 单图拒绝条件

- 主体结构、孔洞数量、支脚或连接关系变化。
- 颜色偏离变体定义或同一组图片颜色不一致。
- 出现品牌外文字、乱码、条码、水印或零售贴纸。
- 多出商品、部件或无法解释的附件。
- 人物年龄不明、疑似未成年、模仿可识别真人，或人体比例、手脚、接触关系和使用姿态不合理。
- 人物遮挡商品关键结构，或人体与商品发生融合、穿模和无支撑悬浮。
- 背景不符合白色展馆、克制影棚或当前品牌语境。

## 浏览器验收

逐项验证：

- `/products` 能发现商品并按系列分组。
- `/series/:slug` 只显示目标系列。
- `/products/:slug` 无查询时使用默认变体。
- 变体切换不跨商品；旧 slug canonical 跳转正确。
- 单变体商品不显示无意义的变体选择器。
- 商品图无 404，GitHub Pages 子路径也能加载。
- 图片声明尺寸与文件真实像素一致，AI 场景可见“品牌 AI 概念影像”。
- 适合人体互动的商品能加载米兰模特图；caption 为“品牌 AI 概念影像 · 米兰造型”，alt 明确“虚构成年米兰模特”及互动方式。
- 商品可加入购物袋，数量只接受有限正整数；设置为 0 表示删除，单笔与终身上限均正确。
- 未知或停售购物袋行可见、可删除、不可结账。
- 混合商品结账生成一个包含多行快照的订单。
- 资格不足的限定和典藏商品只出现“暂时缺货”。
- 1440×1024、1024×768、390×844 无横向溢出和遮挡。
- 键盘焦点、按钮名称、状态提示和 `aria-live` 可用。
- 控制台无错误或 React warning。
